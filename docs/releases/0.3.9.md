# 0.3.9

Android versionCode 74, ARM64, Android 10+.

- Plugin, Skills and MCP lists retry one transient read failure and keep the previous successful category data when a read still fails.
- Explicit tool refresh reloads MCP configuration in app-server before reading the active thread's tools and authentication status.
- RDC entries have dedicated sign-in and sign-out actions. Sign-out removes the OAuth credentials for that named MCP server through the bundled Codex CLI, then restarts the app-server so stale in-memory authorization is not reused. This does not log out the ChatGPT account.
- The Fast mode button prevents pointer focus transfer, preserving the prompt focus while tapping the control so Android WebView can keep the keyboard open.
